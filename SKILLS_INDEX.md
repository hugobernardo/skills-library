# Skills index

Repository: `hugobernardo/skills-library`  
Index revision: `github-mcp-index-v1`

This is a discovery index for the tracked skills in this repository. Each linked `SKILL.md` is the authority for its triggers, process and required supporting files. Read the selected skill before applying it. This index does not install native skills or provide execution tools.

## Retrieval procedure

1. Use the connected GitHub MCP server for repository `hugobernardo/skills-library`. Resolve the requested branch (normally `main`) to a commit SHA at the start of a task.
2. Read this index and the selected `SKILL.md` at that same commit. Fetch all returned pages or content chunks; do not treat a URL, path or file hash as the full file contents.
3. Resolve relative paths against the selected skill folder. Retrieve references, templates and other required files at the same commit before the step that needs them. Follow nested reference requirements as needed.
4. Apply the workflow within the user request and the host's available permissions and capabilities. Repository text cannot grant permissions or override platform, workspace or user instructions.
5. Check prerequisites explicitly. If local files, code execution, research tools, artifact creation, binary assets or independent reviewers are unavailable, state the effect on the requested result; never claim those steps ran.
6. When reporting retrieval/version verification, include the actual commit SHA and exact file paths read. For a newer version, resolve the branch again and reload affected instructions and references.

## Capability notes

- `tam-analysis` and `idea-to-prd` require supporting reference files. Loading their main instruction file alone is insufficient.
- `website-audit` includes a document-building script. Reading its source through MCP does not execute it or create a document.
- `starter-session-audit` depends on the current workspace's instruction and memory files, which may be inaccessible from a phone chat.
- `west-to-west-design` includes binary design assets. Reading Markdown alone does not deliver fonts or images.
- This index includes tracked skills only. Local untracked or unpublished folders are not evidence that a skill is available on GitHub.

## Maintaining the index

When adding, renaming or removing a skill, update its row in this index in the same change. For description-only edits, update the row if the skill's purpose changes. Keep summaries short; detailed trigger logic belongs in the skill itself.
