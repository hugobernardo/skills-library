# Website UI kit

Recreation of westtowest.org (single-page site, source: `reference/website-index.html` from hugobernardo/westtowest-website-v2). Composes the design-system components from `_ds_bundle.js`: NavBar (transparent→frosted on scroll), photographic hero with scrim + ring motif, mission statement, 3-up ServiceCards, 2-up InvolvedCards, TestimonialSlider on Ink, NewsletterForm strip, OfficerCard rows (Officers + Board), SponsorRow, Footer. Officer photos use the initials fallback (live site hotlinks LinkedIn images that expire).
