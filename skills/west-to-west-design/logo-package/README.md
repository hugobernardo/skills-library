# West to West — Logo Package

Lighthouse mark + "WEST TO WEST" wordmark in a keyline box.

## Variants
- **White** — for dark grounds (Ink #0B1220, Dark Ocean #0B3958)
- **Black** (#333333) — for light grounds (White, Cloud #F8FAFC)
- **Red** (#D05353) — standalone brand moments only, never inside UI

## Files
- `svg/` — vector masters (preferred for web)
- `pdf/` — vector masters for print
- `png/` — raster exports at @1x/@2x/@3x, plus `social-avatar@2x.png` (white-on-navy square)

Never redraw, recolor, stretch, or add effects to the mark.
